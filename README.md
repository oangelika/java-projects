# Java projects

Projects written in Java during my computer science studies: OOP, interfaces, collections, enums, GUI.

Each folder is a separate project. Some class names are in Polish.

## Topics covered
- OOP: classes, inheritance, interfaces, abstract classes (oop-animals-objects, zoo-order-figures, interfaces-speakable)
- Generics: generics-flyable
- Collections and Stream API: collections-hash, streams-api, people-comparator
- Concurrency: threads
- GUI (Swing): swing-layouts, swing-window-basics, gui-shapes-frame
